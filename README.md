## 🚀 Run Locally

### Clone the repository

``` bash
git clone https://github.com/Rakhi8076/rakhi-freelance-portfolio.git
```

### Navigate to the project

``` bash
cd rakhi-freelance-portfolio
```

### Install dependencies

``` bash
pnpm install
```

### Start the development server

``` bash
pnpm dev
```

Open `http://localhost:3000` in your browser.
